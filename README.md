# KarttaTesti

Responsiivinen karttasovellus Helsingin nähtävyyksillä. Toimii sekä tietokoneella että puhelimella.

## Teknologiat

- React 19 + TypeScript
- Vite
- Leaflet + react-leaflet (OpenStreetMap)
- Tailwind CSS v4

## Käynnistys

```bash
npm install
npm run dev
```

Avaa selaimessa: http://localhost:5173

## Ominaisuudet

- Interaktiivinen kartta keskitettynä Helsinkiin
- 5 sijaintipistettä popup-tiedoilla
- Responsiivinen layout (mobiili + desktop)
- Kosketustuki (pinch-to-zoom, raahaus)
